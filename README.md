# Superstore Sales Analysis Dashboard

## Project Overview
This project uses Power BI to analyse Superstore sales data and present key business insights through an interactive dashboard.

## Tools Used
- Microsoft Power BI Desktop
- DAX (Data Analysis Expressions)
- Data visualisation and interactive slicers

## Key Performance Indicators (KPIs)
- Total Sales: $2.26M
- Total Orders: 4,922
- Total Customers: 793
- Average Sales per Order: $459.48

## Key Findings
- Technology was the highest performing sales category.
- The West region recorded the highest sales among the regions analysed.
- Monthly sales fluctuated throughout the period.
- November 2018 recorded the highest monthly sales at $87,997.64.
- February 2015 recorded the lowest monthly sales at $12,588.48.

## Recommendations
- Investigate factors contributing to monthly sales fluctuations.
- Review category and regional performance to identify opportunities for improvement.
- Use historical sales patterns to support inventory planning and promotional decisions.
